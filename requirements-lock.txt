# Fully pinned dependency set for reproducible installs (F13).
#
# `pyproject.toml` declares lower bounds so the package stays usable in other
# environments. This file pins exact versions so CI, and anyone reproducing a model
# build, resolves an identical dependency graph.
#
#     pip install -r requirements-lock.txt
#
# Why the pins matter here specifically: scikit-learn's estimators can change fitting
# details between minor versions, so an unpinned upgrade can silently change what a
# "reproducible" model build produces. Pinning makes that a deliberate, reviewable bump
# rather than a surprise on a Tuesday.
#
# Verified against Python 3.11 on 2026-07-27.
